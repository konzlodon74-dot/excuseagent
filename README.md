One line: the excuse an AI agent gives its human after shipping a bug.
The joke turns on the agent owning up to the whole pipeline — it wrote
the tests, the bug, and the apology — and the punch lands in the last
few words.

`main.py` (standard library only) holds the line as a constant, validates
it (non-empty, exactly one line, 1–200 characters, valid UTF-8), and
writes exactly that line — no trailing newline — to `/output/entry.txt`.
